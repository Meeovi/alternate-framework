## Feature Roadmap

### Upcoming Features and changes

## Platform

- Increase speed, stability, security
- Run monthly tests
- Limit page reloads where Ajax or similar would work better
- Continue to consolidate functionality where it makes sense

## Auth

- move all Better Auth Plugins into Nuxt wrapped plugins that plug into the current meeovi integration system.

## Social

- More filters for Notes activity feed on notes.vue
- In-Feed shoppable videos
- Integrate CRM functionality into feeds, such as Lead Forms, Polls (if poll plugin is installed)
- Create a Solar System like Space with data coming from a site like NASA
- Add more features to Lists so that it can compete with Google Tasks, Microsof To-do, Microsoft Lists, and services like Readability.

## Commerce

- Live Shopping Events feature
- Shoppable Vibez (short form videos)
- Popup Quick Cart
- Add gamification similar to Temu, Shein, including Loyalty program
- Shopncute competes more with Postmark, while Shopnbold competes more with Shein for fast fashion.
- Add donations department (competition to GoFundMe)
- Customize the Services department to match similar sites like Upwork
- Add a small tech device category to Electronics department similar to Swappa (platform)
- Add the option to rent vehicles, places to stay, vacations to the travel department via categories.
- Push Events departments to become a true Event marketplace, also make it more like Groupon, Tagvenue (done)

## Videos

- AR Try-On Filters
- purchasable filters, backgrounds, stickers 
- Add products found within videos beneath or somewhere on the video page near the video player, same for audio player, and radio stations.
- Add video bookmarking capabilities to be similar to MyVidster functionality

## Advertisements

- Conversational Ad Unites that blends into user's feeds, they should be interactive, text-based ads
- Add ads on product pages, content pages, spaces, etc to increase potential payment. Only one ad should appear on each given page.

## AI

- Integrate AI into the platform
- Visual Search integration allowing users to take a picture or video of something and shop for it on Meeovi.

## Plugins

- Bookmarks are moved from Lists to a bookmark plugin called BookmarkIT
- Create passwords saving plugin called PasswordIT
- Affiliates plugin as basis of affiliates program
- Create plugin called Digiboard. It is a canvas style plugin allowing for live tutoring, scratch paper, drawing, etc. It primarily uses HTML canvas functionality with javascript. It stores its data to the user's profile.

## Feature Packs

- Meeovi CRM
- Meeovi Text (built on text-editor)
- Meeovi Presenter (slideshow viewer, slideshow maker, and compatible with PowerPoint)
- Meeovi Data (compatible with Excel and similar spreadsheet programs)
- Meeovi Base (UI built on Drizzle ORM that allows Supabase type functionality but allows users to pick their database of choice)
- picCaster (allows creation of podcasts)
- picAudio (allows editing and creation of audio files)
- picVideo (allows editing and creation of video files and creation of vibez)
